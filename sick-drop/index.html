Sick Drop

Sick Drop is a snowboarding rhythm game. The mountain is built to the beat: land on the drop, carve in time, and climb from C to S tier, where the song turns up to 11.

Ride the song

Ten original songs, four riders, one mountain. Every song is its own run. Ride clean, land on the beat, stack the combo and climb the tiers.

Install

  1. Download the zip and unzip it into a folder you can write to. The game saves next to itself, so skip read-only places like /opt.
  2. Open a terminal in that folder and run ./SickDrop.sh
  3. Plug in a gamepad if you have one, or use the keyboard. In the menus, arrows choose, Enter confirms and Esc goes back.
